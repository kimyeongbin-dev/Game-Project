# games — 6종 게임 모듈

각 게임은 독립 패키지에 준하는 경계를 갖는다. 게임 모듈 간 직접 참조 금지,
공통 기능은 `lib/core/` 를 경유한다.

| 모듈 | 게임 | 명세 |
| :-- | :-- | :-- |
| `maze_1p/` | 1인칭 미로 대결 (Fog of War, 1:1 / 1:1:1) | §4.1 |
| `word_puzzle/` | 낱말 퍼즐 (다중 테마 크로스워드) | §4.2 |
| `photo_jigsaw/` | 퍼즐 맞추기 (커스텀 사진 & 시크릿 편지) | §4.3 |
| `number_ten/` | 합 10 드래그 제거 퍼즐 | §4.4 |
| `color_tile/` | 컬러 타일 (교차점 제거 퍼즐) | §4.5 |
| `gomoku_renju/` | 오목 (렌주룰) | §4.6 |

무거운 연산(로컬 AI 수읽기, 역산 보드 생성, 이미지 분할)은 반드시
`Dart Isolate` 로 분리하여 UI 프레임을 방어한다.

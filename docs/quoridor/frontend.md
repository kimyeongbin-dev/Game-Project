# FrontDesign.md: 통합 게임 플랫폼 디자인 시스템

## 1. 디자인 철학 (Design Philosophy)
- **일관성 (Consistency):** FastAPI(백엔드)와 Flutter(프런트엔드) 간의 데이터 흐름과 시각적 언어를 통일함.
- **직관성 (Intuitivity):** 별도의 설명 없이도 게임 규칙(이동, 벽 설치)을 이해할 수 있는 사용자 중심 인터페이스.
- **확장성 (Scalability):** 향후 추가될 다양한 보드게임(체스, 오목 등)에서도 재사용 가능한 모듈형 UI 컴포넌트 설계.

---

## 2. 쿼리도(Quoridor) UI 가이드라인

### 2.1 게임 보드 레이아웃
- **그리드 시스템:** 9x9 격자 구조. 칸(Square)은 이동 경로이며, 칸 사이의 틈(Gap)은 벽이 설치되는 공간임.
- **시각적 계층 구조:**
    - 보드판은 배경과 명확히 구분되어야 함.
    - **벽 스냅(Snap):** 드래그 중인 벽이 '틈(Gap)' 근처에 오면 해당 위치에 반투명한 미리보기가 나타나야 함.
    - **이동 하이라이트:** 현재 턴인 플레이어가 이동 가능한 칸을 부드러운 테두리로 강조함.
- **상태 패널 (Status Panel):** 화면 상단 또는 측면에 고정하여 현재 턴, 남은 벽 개수, 타이머 표시.

### 2.2 색상 팔레트 (Minimalist Black & White / Ivory)
- **전체 배경 (Background):** 매트 블랙 (#1A1A1A) 
- **게임 보드 (Board Base):** 부드러운 아이보리 (#F9F9F7)
- **보드 격자/라인 (Grid Lines):** 아주 연한 그레이 (#E0E0E0)
- **플레이어 1 (나):** 퓨어 화이트 (#FFFFFF) + 미세한 DropShadow
- **플레이어 2 (AI):** 딥 블랙 (#000000) + 미세한 DropShadow
- **설치된 벽 (Placed Walls):** 미드나잇 블루 또는 다크 그레이 (#333333).
- **상호작용 하이라이트:**
    - 이동 가능 칸: 연한 베이지 (#F5F5DC) 테두리.
    - 벽 배치 스냅: 50% 불투명도의 벽 에셋 이미지.

## 3. Flutter 구현 및 입력 방식

### 3.1 컴포넌트 구조
- **GameCanvas:** `CustomPainter`를 사용하여 보드 기저와 고정된 말/벽을 렌더링.
- **DragLayer:** Flutter `Draggable` 위젯을 사용하여 하단 인벤토리의 벽 에셋을 이동시킴.
- **DropZone:** 보드의 각 '틈(Gap)' 위치에 `DragTarget`을 배치하여 스냅 및 드롭 감지.

### 3.2 입력 방식 (Drag & Drop)
- **말 이동:** 이동 가능한 칸(Square)을 탭(Tap)하여 즉시 이동.
- **벽 설치:**
    - 하단 UI의 벽 창고에서 가로(`wall_h.png`) 또는 세로(`wall_v.png`) 에셋을 드래그 시작.
    - 보드 위 유효한 '틈' 영역 통과 시 미리보기 표시.
    - 드롭 시 FastAPI에 좌표 및 방향 데이터를 전송하여 검증 후 최종 배치.

---

## 4. API 연동 및 UX 처리
- **실시간 통신:** WebSockets를 통해 상대방(AI)의 이동을 즉각 반영.
- **로딩 피드백:** AI 연산 중에는 상대방 말 주변에 부드러운 Pulse 애니메이션 적용.
- **오류 피드백:** 유효하지 않은 벽 설치 시 벽이 원래 위치로 돌아가는(Reset) 애니메이션과 토스트 알림.
